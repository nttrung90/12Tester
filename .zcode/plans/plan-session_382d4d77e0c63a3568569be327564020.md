# Thêm hiển thị xếp hạng của người dùng hiện tại vào tab "Xếp hạng"

## Tổng quan
Tab Xếp hạng (page 3 của HorizontalPager trong `HomeScreen.kt`) hiện chỉ hiển thị Top 100 từ RPC `get_leaderboard_v2`, không có bất kỳ chỉ thị nào về vị trí của người dùng hiện tại. Tính năng mới gồm 2 phần:

1. **Thẻ "Hạng của bạn" ghim** ngay dưới sub-tab Top Credit — luôn thấy khi cuộn, hiển thị hạng chính xác (kể cả ngoài Top 100) + tổng số thành viên + credits/stats.
2. **Highlight dòng của mình** trong danh sách Top 100 — màu nền khác + chip "Bạn".

Hạng chính xác lấy từ RPC mới `get_my_rank_v1` (dùng `auth.uid()`, cùng thuật toán sắp xếp với `get_leaderboard_v2`).

---

## 1. SQL Migration — `supabase/migrations/038_my_rank.sql` (mới) + mirror vào `supabase/full_schema_singapore.sql` (sau khối `get_leaderboard_v2` ~line 2912)

```sql
create or replace function public.get_my_rank_v1(p_sort text default 'credit')
returns jsonb
language plpgsql
security definer
set search_path = public
stable
as $$
-- Tính hạng chính xác của auth.uid() theo cùng thứ tự sắp xếp với get_leaderboard_v2:
-- 'credit': credits desc, checkin_count desc, campaigns_count desc
-- 'test'  : checkin_count desc, credits desc, campaigns_count desc (chỉ tính khi có >= 1 checkin)
-- Cách tính: đếm số người xếp trên mình (so sánh bộ ba) + 1, kèm count(*) tổng profiles.
-- Trả về: {rank, credits, checkinCount, campaignsCount, totalUsers}; '{}' nếu không xác định được.
$$;

grant execute on function public.get_my_rank_v1(text) to authenticated;
notify pgrst, 'reload schema';
```

Chi tiết: tính stats của mình (credits + 2 subquery đếm checkins) → `rank = count(profiles có (credits, cc, cac) > (my_credits, my_cc, my_cac)) + 1` (so sánh từng cột trong WHERE vì Postgres row comparison với subquery phức tạp không gọn) → build jsonb object. Branch `'test'`: hoán đổi thứ tự so sánh và trả `{}` nếu mình có 0 checkin. Trả `coalesce(v_result, '{}'::jsonb)`.

- Thêm method sau `getLeaderboard` (line 867):
```kotlin
suspend fun getMyRank(sort: String = "credit", forceRefresh: Boolean = false): MyRank?
```
  - Trả `null` ngay nếu `!isAuthenticated()`.
  - `deduped("myRank:$sort", forceRefresh, isFresh, { cachedMyRank })` với TTL `CACHE_TTL_MS` như các method khác.
  - **RPC-first**: `supabase.postgrest.rpc("get_my_rank_v1", MyRankParams(sort)).decodeAs<MyRank>()` (mọi field có default nên `{}` decode an toàn).
  - **Fallback** nếu RPC chưa deploy/lỗi:
    1. Tìm mình trong leaderboard đã cache/tải: `getLeaderboard(sort).firstOrNull { it.userId == currentUserId() }` → map sang `MyRank` (totalUsers không có → để 0, UI ẩn phần "/ tổng").

    3. Tất cả đều lỗi → `null` (UI ẩn thẻ).
